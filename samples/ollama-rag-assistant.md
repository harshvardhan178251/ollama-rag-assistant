# Ollama RAG Assistant

A fully local, keyless Retrieval-Augmented Generation assistant. You index a
folder of documents once, then ask questions; the answer is generated by a
local model running in Ollama, grounded strictly in the retrieved chunks.

Everything runs on localhost. No API keys, no telemetry, no network calls
leaves your machine except to the Ollama server you control.

## Why

Cloud LLM APIs charge per token and require sending your data to a third
party. For personal knowledge bases, internal documentation and air-gapped
environments, a local pipeline is the better default.

## How it works

1. `rag-assistant index <path>` reads your markdown and text files, splits
   them into overlapping chunks and embeds each chunk with the
   `nomic-embed-text` model.
2. Every embedding is stored in a plain SQLite database next to your
   documents. No external vector database is required.
3. `rag-assistant ask "..."` embeds the question, ranks chunks by cosine
   similarity and builds a prompt containing the best chunks.
4. A chat model (default `qwen2.5:3b`) answers using only that context and
   cites the sources it used.

## Components

- Chunker: packs paragraphs into chunks with configurable size and overlap.
- Vector store: SQLite-backed, cosine similarity in pure Python.
- Ollama client: talks to the Ollama HTTP API over localhost.
- CLI: `index`, `ask`, `stats`, `clear`, `serve`.
- Web UI: an optional local chat page on port 8765.
